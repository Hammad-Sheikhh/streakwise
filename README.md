# Streakwise

A study tracker for long-term goals: log study time in seconds, see a GitHub-style heatmap and
streaks, track weekly targets, share reports with teachers and parents, and let Claude log and analyse
your progress through an MCP connector.

## Tech stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · TanStack Query · Zod · Netlify Functions ·
Supabase (Postgres) · Model Context Protocol (MCP) · Vitest · Playwright
